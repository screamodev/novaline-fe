### Performance fixes

| Problem | Cause | Fix |
|---|---|---|
| CLS 0.28 on mobile home and other pages | Removing the Viber icon made the 3-phone top bar wrap depending on the font: the fallback font is wider than Manrope. `@nuxt/fonts` generated `size-adjust:100%` fallbacks because the Google provider forces the generic `sans-serif`, which has no metrics. | Explicit metric fallbacks `Manrope Fallback` / `Unbounded Fallback` (Arial, values from fontaine) in `main.css`, referenced from `tailwind.config.ts`. CLS dropped to ≈ 0, including the hero-title reflow (Unbounded is 35% wider than Arial). |
| Render-blocking `entry.css` (~0.5–1 s) | Global Tailwind CSS was a separate stylesheet | `features.inlineStyles: true`. Home FCP went from 3.3 s to 1.7 s. |
| Fonts competing with the LCP image | 3 font preloads (108 KB) at VeryHigh priority | Font preload off (metric fallbacks make it unnecessary). Unused weights dropped (Unbounded 500, Manrope 800); subsets limited to cyrillic + latin. |

## Deployment dry run

The full DEPLOY.md flow ran end to end on production images:
1. `up db cms`.
2. Token from the log → `web.env`.
3. `npm run seed` inside the production image.
4. `up`: web started only after cms was healthy.

**Checks through Caddy:**
- Routes: all 200.
- Redirects:
  - `/dogovir.pdf` → 302 to the CMS file;
  - legacy `/home/tv/` → 301 `/#tv`;
  - `/private-cabinet/` → 301 stat.novaline.net.
- Staging indexing: `robots.txt` has `Disallow: /`, plus `X-Robots-Tag: noindex`.
- Webhook: cms → `web:3000/api/revalidate` purged 13 cache entries.
- Lead: the lead reached the database.
- Assistant: demo-mode answer.

**Backup and restore:** after `backup.sh`, 36 plans, 1 lead and the offer PDF were deleted. `restore.sh` brought them all back, and `/dogovir.pdf` returned 200 again.

## Known limits / for the client

- Fallback (demo) assistant replies are fixed CMS texts. Their prices must be updated manually if tariffs change. The live assistant always uses current prices.
- The legal entity name and company code (ЄДРПОУ) are not published anywhere. `orgLegalName` stays empty until the client provides it.
- The privacy policy was written from the actual data flows. A lawyer should review it before launch.
- The 6 news articles are demo content.
- Android devices without Arial fall back to an unadjusted system font. There, CLS from the font swap is possible but small.
