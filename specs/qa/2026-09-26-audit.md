# QA audit — 2026-09-26

**Scope**: every route (`/`, `/en`, `/news`, `/news/<slug>`, `/en/news/<slug>`, `/internet`, `/internet/<slug>`, `/radio`, `/privacy`, 404) at **1440, 1280, 390, 360** CSS px (+1100 for the nav breakpoint), all landing sections, interactions (nav, "More" menu, drawer, language switch, plan tabs, TV filter, payment accordion, coverage search/cascade/map, lead form, callback dialog, radio player).

**Method**: the user's Chrome via the Claude extension. The browser runs at 75 % zoom for localhost, so an exact-width same-origin iframe harness was used to get true CSS viewports. Plus scripted checks per page: horizontal overflow, broken images, `undefined`/`null`/raw i18n keys, touch targets < 44 px, console/hydration warnings, and a crawl of every internal link (96 URLs).
